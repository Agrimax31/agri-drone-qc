# AgriDrone QC

Application de gestion pour opérateurs de drones agricoles au Québec.

Inspirée d’AgTrack (nuWay Ag), adaptée au contexte canadien/québécois.

## Objectifs
- Gérer clients, champs et jobs d’application par drone
- Calculateur de mélanges et recettes
- Calculateur de lots automatique
- Météo automatique liée aux logs
- Rapports de conformité (Transport Canada + registre pesticides)
- Interface en français

## Écrans principaux (prototype)
1. Accueil / Liste des jobs
2. Détail d’un job + météo
3. Calculateur de mélange
4. Calculateur de lots
5. Rapports
6. Parcelles & Clients

## Stack prévue
- Frontend : Base44 (React/Vite) ou solution ouverte
- Données : Base de données Base44 ou Supabase
- Dépôt : ce repository GitHub
